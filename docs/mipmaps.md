# Mipmap при сборке

`cargo build -p hookrunner-game` автоматически рассчитывает mipmap непрозрачных текстур карты и glow-текстур. Фильтрация в линейном цветовом пространстве перенесена из клиента без изменения алгоритма. Прозрачные материалы, lightmap и небо сохраняют прежний путь загрузки.

Готовые уровни сохраняются в PNG-атласах в генерируемом каталоге `assets/stormkeep/built/mipmaps/`. Они сжаты без потерь и поддерживаются существующим PNG-загрузчиком на WebGL 2 и native. Клиент декодирует PNG, копирует строки готовых уровней в layout GPU и загружает текстуру; вычислений mipmap при запуске больше нет. Атлас требует временной памяти для декодирования; финальный размер текстуры на GPU не меняется.

Cargo отслеживает исходные PNG, метаданные карты и код генератора. Кеш в `OUT_DIR` позволяет пересчитывать только изменившиеся текстуры; изменение алгоритма инвалидирует кеш. Удалённые или повреждённые выходные файлы восстанавливаются следующей сборкой. Изменение Rust-кода игры не требует повторной фильтрации текстур.

`scripts/build-web.sh` публикует готовые атласы вместо исходных непрозрачных PNG. Генерируемые файлы не нужно коммитить. Для native генерация также запускается автоматически при обычной сборке; при запуске из корня репозитория клиент находит атласы в `assets/`.

Каждый PNG содержит уровни сверху вниз, начиная с оригинала; ширина равна ширине оригинала. Строки меньших уровней дополнены нулями справа. Сгенерированная таблица `mip_assets.rs` хранит исходные размеры и число уровней. Клиент удаляет заполнение простым копированием строк. Алгоритм фильтрации находится в `scripts/mip_filter.rs`, вызывается только из `crates/game/build.rs` и не включается в WASM.
