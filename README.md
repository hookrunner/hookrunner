# Hookrunner

Многопользовательский аренный шутер на Rust, Bevy и Lightyear. Сервер и клиенты используют общую симуляцию на 120 Гц. В репозитории уже есть собранные ассеты Stormkeep и пистолета; для обычного запуска Blender и компилятор карт не нужны.

## Подготовка

Проект использует Rust 1.94.0 из `rust-toolchain.toml`:

```sh
rustup toolchain install 1.94.0 --profile minimal --component rustfmt,clippy --target wasm32-unknown-unknown
cargo fetch --locked
```

Для нативного клиента на Ubuntu 24.04:

```sh
sudo apt-get install -y build-essential pkg-config libx11-dev libwayland-dev libxkbcommon-dev libxrandr-dev libxi-dev libvulkan1 mesa-vulkan-drivers
```

Для браузерного клиента нужны Python 3.11+ и версия wasm-bindgen, совпадающая с `Cargo.lock`:

```sh
cargo install wasm-bindgen-cli --version 0.2.128 --locked
export PATH="$HOME/.cargo/bin:$PATH"
```

## Игра в браузере — основной вариант

В корне репозитория:

```sh
cargo build --locked -p hookrunner-server
./scripts/build-web.sh
```

В первом терминале запустить сервер:

```sh
RUST_LOG=info HOOKRUNNER_BIND=127.0.0.1:5000 ./target/debug/hookrunner-server
```

Дождаться строки `Loading game [4/4, 100%]: ready for players`. Во втором терминале:

```sh
python3 scripts/serve-web.py --bind 127.0.0.1 --port 8080
```

Открыть http://127.0.0.1:8080 в обычном браузере с WebGL 2. Встроенный браузер Codex в проверенном окружении не смог создать WebGL 2 контекст. Другая вкладка или второй клиент подключаются к тому же серверу. URL сервера можно задать параметром страницы `?server=ws://127.0.0.1:5000`.

После изменения общей симуляции, серверного или сетевого кода пересобрать сервер и используемый клиент: сервер отклоняет несовпадающий отпечаток сборки. При обновлении браузерной сборки страница автоматически перезагружается. Остановка процессов: Ctrl+C в соответствующих терминалах.

## Нативный клиент (дополнительно)

В корне репозитория:

```sh
cargo build --locked -p hookrunner-server -p hookrunner-game
```

В первом терминале запустить сервер только на локальном интерфейсе:

```sh
RUST_LOG=info HOOKRUNNER_BIND=127.0.0.1:5000 ./target/debug/hookrunner-server
```

Дождаться строки `Loading game [4/4, 100%]: ready for players`. В другом терминале:

```sh
./target/debug/hookrunner --server ws://127.0.0.1:5000
```

## Управление

- Клик по игре — захват мыши; Esc — освобождение.
- WASD — движение.
- Space — прыжок, ещё одно нажатие в воздухе — дополнительный прыжок.
- Shift — рывок (два восстанавливающихся заряда).
- Левая кнопка мыши — стрельба.

## Структура

- `crates/shared` — протокол, движение, оружие и коллизии карты.
- `crates/server` — авторитетная симуляция и обработка попаданий.
- `crates/client` — сеть и предсказание клиента.
- `crates/game` — графика, ввод, HUD, нативная и браузерная платформы.
- `scripts` — сборка веб-клиента и инструменты подготовки ассетов.

Сборка без `-p hookrunner-game` по умолчанию не включает графический клиент. Прогресс загрузки сервера показывает завершённые этапы, а не оценку оставшегося времени. Карта и коллизии загружаются синхронно; 100% появляется после подтверждения открытия сетевого порта.

Основной продукт — браузерная версия. Игровая логика и игровой UI остаются в Rust/Bevy, чтобы нативный клиент имел такое же поведение. HTML/JavaScript используются для загрузки и интеграции с браузером.
